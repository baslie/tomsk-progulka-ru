## Скрытый раздел «Статьи» — НЕ удалять код и контент

Раздел «Статьи» **временно скрыт** от посетителей по просьбе автора проекта. К нему вернутся и продолжат работу позже. **Это скрытие, а не удаление.**

**Категорически нельзя** удалять или «вычищать как мёртвый код»:

- контент статей — `src/content/articles/*.md` (сейчас 2 файла);
- схему коллекции `articles` в `src/content.config.ts`;
- страницы раздела — `src/pages/articles/index.astro` и `src/pages/articles/[slug].astro`;
- каталог/карточки статей — `src/components/articles/*` (`ArticlesCatalog.tsx` и пр.);
- метки категорий `ARTICLE_CATEGORY_LABELS` в `src/lib/constants.ts`.

Хотя страницы сейчас не генерируются, а ссылок в интерфейсе нет, этот код **рабочий и нужный** — он оживёт, как только раздел вернут.

### Как устроено скрытие (один переключатель)

Всё завязано на единственный флаг `ARTICLES_VISIBLE` в `src/lib/constants.ts`:

- `Header.astro` — пункт «Статьи» добавляется в меню только при `ARTICLES_VISIBLE === true`;
- `src/pages/articles/index.astro` — при `false` делает `Astro.redirect("/")`;
- `src/pages/articles/[slug].astro` — при `false` `getStaticPaths()` возвращает `[]` (страницы статей не публикуются);
- `astro.config.mjs` — `sitemap({ filter })` исключает `/articles` из карты сайта.

**Чтобы вернуть раздел** — поставить `ARTICLES_VISIBLE = true` в `src/lib/constants.ts`. Больше ничего менять не нужно. Если потребовалось убрать сам флаг или его проверки — это допустимо только по явной просьбе человека.

## Dev-сервер: `npm run dev` запускает ТОЛЬКО человек

**Команду `npm run dev` запускает исключительно пользователь (человек). AI-агент НЕ запускает dev-сервер самостоятельно.**

Сайт уже работает на локальном dev-сервере по адресу **http://localhost:4321/**.

Правила для агента:

- Если для задачи нужно открыть сайт (проверить вёрстку, сделать скриншот, протестировать страницу) — **используй уже запущенный сервер на http://localhost:4321/**. Не поднимай новый сервер на другом порту.
- **Не запускай** `npm run dev`, `astro dev` или любой другой dev-сервер.
- Если порт **4321 не отвечает** (ошибка подключения, сервер не запущен) — **попроси пользователя запустить `npm run dev` вручную** и дождись подтверждения. Не пытайся обойти это запуском своего сервера.

Команды, которые агенту запускать **можно** (они не поднимают постоянный dev-сервер):

- `npm run build` — сборка статики
- `npm run check` / `astro check` — проверка типов
- `npm install`, `npm audit` и т.п.

## Неразрывные пробелы в текстах

При наполнении страниц и маршрутов осмысленным русским текстом расставляй неразрывные пробелы. Это пожелание автора проекта — оно касается всего пользовательского текста (контент страниц, описания и тело маршрутов, видимые подписи).

### Где ставить неразрывный пробел

- После одно- и двухбуквенных предлогов и союзов, чтобы они не висли в конце строки: `в`, `и`, `с`, `к`, `о`, `у`, `а`, `но`, `на`, `по`, `за`, `от`, `до`, `из`, `не`, `мы` и т. п. Пример: `гуляем по⍽маршрутам`, `и⍽от⍽Тимирязево`.
- Перед тире `—`: неразрывный пробел **перед** тире, обычный — после. Пример: `общение⍽— лес всех делает лучше`.
- Между числом и относящимся к нему словом/единицей: `120⍽человек`, `7⍽км`, `2016⍽году`, `Вариант⍽1.`, `автобус⍽№36`.
- После сокращений перед словом: `оз.⍽Песчаное`.
- Числовые диапазоны записывай через тире, а не дефис: `10–20⍽человек` (не `10-20`).

(`⍽` здесь — условное обозначение неразрывного пробела для наглядности.)

### Чем вставлять — зависит от типа файла

Это критично, иначе пробел отрендерится буквально или не вставится вовсе.

- **Обычный `.md` (без JSX), тело markdown** — используй HTML-сущность `&nbsp;`. Она видна в исходнике и корректно рендерится. Пример: `по&nbsp;лесным тропинкам`.
- **`.mdx` с JSX-компонентами, YAML-frontmatter, строковые пропсы компонентов (`caption`, `title`, `text`, `description`)** — используй **настоящий символ U+00A0**, а НЕ `&nbsp;`.
  - Причина: `description` из frontmatter уходит в HTML-атрибут `<meta name="description">` и в видимые карточки (`RouteCard.tsx`), а пропсы компонентов — это JS-строки. Там `&nbsp;` попадёт в разметку буквально (как текст «&nbsp;»), а не превратится в пробел.
  - Символ U+00A0 одинаково корректно работает в YAML, markdown, JSX-тексте и атрибутах.
- **`alt`-тексты картинок не трогай** — они для скринридеров, неразрывный пробел там бессмысленен.

### Как технически вставить U+00A0

Инструмент **Edit «схлопывает» U+00A0 в обычный пробел** при передаче параметров — точечная правка с ручной вставкой символа не сработает (old и new окажутся идентичными). Надёжные способы:

- **`Write`** сохраняет U+00A0 корректно — можно записать весь файл целиком.
- **Node-скрипт** со списком замен `[что, на_что]`, где неразрывный пробел задан через `String.fromCharCode(0x00A0)` (не литералом). Скрипт должен падать с ошибкой, если фрагмент не найден, — так ловятся опечатки. После прогона удали скрипт.

### Проверка результата

После сборки (`npm run build`) проверь готовый HTML в `dist/`:

- литеральных `&nbsp;` должно быть **0** (иначе где-то сущность попала в JSX-проп/атрибут);
- символов U+00A0 — больше нуля.

`grep -P` в этом окружении не работает с UTF-8 — считай символы через Node:
`node -e "const s=require('fs').readFileSync('dist/.../index.html','utf8');console.log((s.match(/ /g)||[]).length)"`
