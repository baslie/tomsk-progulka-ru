# CLAUDE.md — Томская Прогулка

Инструкции для AI-агентов, работающих с этим проектом.

## Dev-сервер: `npm run dev` запускает ТОЛЬКО человек

**Команду `npm run dev` запускает исключительно пользователь (человек). AI-агент НЕ запускает dev-сервер самостоятельно.**

Сайт уже работает на локальном dev-сервере по адресу **http://localhost:4321/**.

Правила для агента:

- Если для задачи нужно открыть сайт (проверить вёрстку, сделать скриншот, протестировать страницу) — **используй уже запущенный сервер на http://localhost:4321/**. Не поднимай новый сервер на другом порту.
- **Не запускай** `npm run dev`, `astro dev` или любой другой dev-сервер.
- Если порт **4321 не отвечает** (ошибка подключения, сервер не запущен) — **попроси пользователя запустить `npm run dev` вручную** и дождись подтверждения. Не пытайся обойти это запуском своего сервера.

Команды, которые агенту запускать **можно** (они не поднимают постоянный dev-сервер):

- `npm run build` — сборка статики
- `npm run check` / `astro check` — проверка типов
- `npm install`, `npm audit` и т.п.
